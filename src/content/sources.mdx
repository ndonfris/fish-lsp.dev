# Sources

## Source Code Repos

The `fish-lsp` project uses a collection of repositories to implement the language server and client ***(NOT a <ins>mono-repo</ins>)***.

The following is a list of the major repositories that are used in the project:

- [`fish-lsp`](https://github.com/ndonfris/fish-lsp) - The main repository of the language-server  
- [`fish-lsp.dev`](https://github.com/ndonfris/fish-lsp.dev) - The website source code.
- [`vscode-fish-lsp`](https://github.com/ndonfris/vscode-fish-lsp) - The plugin/extension for [VSCode](https://code.visualstudio.com/)/[VSCodium](https://vscodium.com/) support
- [`fish-lsp-language-clients`](https://github.com/ndonfris/fish-lsp-language-clients/) - Collection of <ins>***various***</ins> language clients configurations.
- [`jetbrains-fish`](https://github.com/tox-dev/jetbrains-fish?tab=readme-ov-file#installation) - The [IntelliJ](https://www.jetbrains.com/idea/) plugin for fish-lsp.
- [`zed-fish-lsp`](https://github.com/alysson-souza/zed-fish-lsp) - The [Zed]() plugin for fish-lsp

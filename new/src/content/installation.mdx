# Installation

`fish-lsp` requires **Node.js `>= 20`** (the project is developed against
`node@22.14.0`). Some language clients — e.g. the
[VSCode](https://marketplace.visualstudio.com/items?itemName=ndonfris.fish-lsp) /
[VSCodium](https://open-vsx.org/extension/ndonfris/fish-lsp) extension — bundle
the server for you, so manual installation isn't always required.

For everyone else, pick one of the methods below.

## Package Manager

Pick your package manager. Stability across package managers can vary — if one
gives you trouble, try another method.

> Package availability and freshness vary by ecosystem. The npm registry always
> has the latest release.

## Standalone Binary

Download the prebuilt standalone binary directly from the GitHub releases — no
Node.js or package manager required.

```fish
# Download the latest standalone binary
curl -L https://github.com/ndonfris/fish-lsp/releases/latest/download/fish-lsp.standalone \
  -o ~/.local/bin/fish-lsp

# Make it executable
chmod +x ~/.local/bin/fish-lsp
```

> [!IMPORTANT]
> Ensure `~/.local/bin` is in your `$PATH` so the `fish-lsp` command is found.

## Build from Source

The most portable method. Recommended toolchain: `yarn@1.22.22`,
`node@22.14.0`, `fish@4.0.8`.

```fish
git clone https://github.com/ndonfris/fish-lsp
cd fish-lsp

yarn install
yarn build   # links ./dist/fish-lsp into your `yarn global bin` $PATH
```

See [Building from Source](/docs/building-from-source) for troubleshooting
(manual linking, the tree-sitter `.wasm`, and re-linking for VSCode).

## Shell Completions

Generate fish completions for the `fish-lsp` command itself:

```fish
fish-lsp complete > ~/.config/fish/completions/fish-lsp.fish
```

> [!NOTE]
> Completions are needed for package-manager installs. Source builds write them
> automatically during `yarn build`.

## Verify the Installation

```fish
# show the help output
fish-lsp --help

# show build version, paths, and health
fish-lsp info
```

If `fish-lsp` isn't found afterwards, confirm the install location is on your
`$PATH` (`fish-lsp info --bin` prints the resolved binary path). See
[Debugging](/docs/debugging) for more.

## Next Steps

After installing, [configure your editor](/docs/client-configurations) to launch
`fish-lsp start` for `fish` files, and optionally tune the
[server settings](/docs/server-configurations).

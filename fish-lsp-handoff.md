### Path aliases (tsconfig.json `compilerOptions.paths`)

```

@layouts/*    → src/layouts/*

@content/*    → src/content/*
```

## 3. Agent Handoff Prompt

---

### Context

You are continuing work on **fish-lsp.dev**, the documentation and marketing website for
[`fish-lsp`](https://github.com/ndonfris/fish-lsp) — a TypeScript LSP implementation for the
[fish shell](https://fishshell.com). The project is a static Astro site built with TypeScript,
Tailwind v4, Alpine.js, and React. It serves from a single canonical root:

- `fish-lsp.dev` — homepage (marketing, install tabs, feature grid)
- `fish-lsp.dev/page/:slug` — documentation pages

Cross-page links are built from `DOCS_ORIGIN` in `src/config.ts`: during `pnpm dev` the origin
is empty so links are relative (`/page/installation` → `localhost:4321`), and in `pnpm build`
the origin is `https://fish-lsp.dev` so links become absolute. Update `SITE_ORIGIN` in
`src/config.ts` if the production root ever moves (e.g. back to a `docs.` subdomain).
The playground lives at `https://fish-lsp.dev/playground` (already built by the project owner —
it exists, link to it freely).

---

### What has been built

A complete Astro project (`fish-lsp-dev/`) with:

**Homepage (`src/pages/index.astro`)**
- Sticky nav: `[🐟 fish-lsp] · Docs · ▶ Playground · [GitHub SVG icon] · [npm SVG icon]`
- Hero section with animated terminal window (blink cursor, fish-shell prompt colours)
- 8-card feature grid + a 9th "Playground ↗" card with distinct cyan border
- Tabbed install block (pnpm / npm / yarn / brew / pacman)
- SSG doc cards grid (built from content collection at build time, all link to docs subdomain)
- Animated wave footer

**Docs (`src/layouts/DocsLayout.astro` + `src/pages/page/[slug].astro`)**
- Floating sidebar (`position: absolute`) — does **not** push or shrink prose width
- On desktop (≥768px): sidebar lives in the left margin, semi-transparent with blur; a "nav" tab
  sticks out from its right edge to collapse/expand it
- On mobile (<768px): sidebar is an off-canvas drawer, toggled by a hamburger in the topbar;
  backdrop overlay when open
- Topbar: `[🐟 fish-lsp] [docs] · spacer · [▶ Playground] · [GitHub icon] · [npm icon]`
- Full-width `<main>` with `padding-left: calc(220px + 2.5rem)` on desktop so prose starts
  after the sidebar without the sidebar being in the flex row
- Syntax-highlighted prose (`class="prose"`) via Shiki (`material-theme-ocean`)

**Content (6 markdown pages)**
- `installation`, `building-from-source` → section: Getting Started
- `client-configurations` → section: Configuration
- `features`, `debugging`, `how-it-works` → section: Reference
- Each has `order:` and `section:` frontmatter fields used for sidebar grouping and sort

**Preview artifact (`fish-lsp-site-preview.jsx`)**
- A self-contained React artifact that simulates the full site with a browser chrome (traffic
  lights, URL bar that updates domain on navigation: `fish-lsp.dev` ↔ `docs.fish-lsp.dev/page/*`)
- Includes Prism.js syntax highlighting (loaded from cdnjs at runtime) for fish/bash, lua, json,
  plaintext blocks
- The floating sidebar behaviour is driven by a `ResizeObserver` on the scroll container
  (`containerWidth` prop) — wide ≥780px uses the floating margin sidebar; narrow uses the drawer

### Design decisions (important to preserve)

**Palette (CSS custom properties in `src/styles/global.css`)**
```
--fish-blue:  #4e6cfa   primary accent, nav CTA, active sidebar item
--fish-cyan:  #64d2ff   code, playground link, feature card names
--fish-green: #32d583   terminal version output
--fish-yellow:#ffd166   flags in terminal, strong in prose
--fish-red:   #ff6b6b   npm icon hover
--bg-0: #0a0d14  page background
--bg-1: #0f1320  cards, sidebar, code blocks
--bg-2: #141829  hover states, blockquotes
--bg-3: #1c2236  inline code background
--border: rgba(78,108,250,0.2)
--font-mono: 'JetBrains Mono', ...  (loaded from Google Fonts)
--font-sans: 'Inter', system-ui, ...
```

**Sidebar layout approach**
The sidebar is `position: absolute` (scoped to the scroll container), NOT in a flex row with main.
`<main>` is `width: 100%` with `padding-left: calc(220px + 2.5rem)`. This means expanding/
collapsing the sidebar never changes prose width — content stays stable.

**Header layout**
Both navbars are flat flex rows with a single `gap: 16` and `padding: 0 16px`.
Structure: `[logo] [badge?] [flex:1 spacer] [nav items]`.
`width: 100%; box-sizing: border-box; overflow: hidden` prevents overflow on narrow screens.
GitHub and npm use SVG icon links (no text), right-justified after Playground.

**LogoMark on mobile**
`LogoMark` is always an inline row (`flex-direction: row`) — on narrow viewports the icon shrinks
to 14px and text to 13px so the whole logo fits in one text-height row and aligns with other nav items.
The previous "stacked column" approach was abandoned because it caused height misalignment.

**Playground link placement**
Three surfaces: homepage nav (cyan text link), docs topbar (outlined cyan pill), homepage feature
grid (9th card with cyan border + `↗`). Rationale: homepage nav reaches new visitors; docs topbar
reaches users deep in docs who want to test a behaviour live; feature card is earned placement
after reading what the server does.

**Syntax highlighting in the artifact**
Prism.js is loaded once via a module-level promise (`prismPromise`). Language components
(bash/fish, lua, json) are lazy-loaded on first use into a `loadedLangs` Set to avoid duplicate
`<script>` tags. Fish maps to the `bash` grammar (Prism has no fish grammar). Token colours
use Material Ocean overrides injected via a `<style>` tag inside `CodeBlock`.

### Known remaining work / issues to pick up

1. **Prism fish grammar** — fish currently uses the `bash` Prism grammar which is close but misses
   fish-specific keywords (`funced`, `abbr`, `set -Ux`, etc.). A custom Prism language definition
   for fish would improve accuracy.

2. **Docs sidebar mobile toggle** — the sidebar drawer open/close state lives in `DocsLayout.astro`
   as Alpine.js state on the `<aside>`. The hamburger button in the Astro layout needs the
   `x-data` / `@click` wiring added (the React preview artifact has this working; the Astro
   source layout has the CSS classes but the Alpine toggle was not wired in the final commit).

3. **`docs` badge visibility** — currently hidden below 480px via `display: none`. On the Astro
   layout this is controlled by the `@media (max-width: 480px) { .docs-topbar__badge { display: none } }`
   rule in DocsLayout. Consider whether this is the right breakpoint.

4. **Playground page** — `fish-lsp.dev/playground` exists and works. The owner noted "works great
   aside from a select few features could be improved" — these improvements are out of scope for
   this task but the link is live and correctly placed.

5. **Deploy target** — three platform configs are included (Vercel `vercel.json`, Cloudflare Pages
   `public/_redirects` + `public/_headers`, Fly.io `fly.toml` + `Caddyfile`). The owner has not
   committed to a platform yet. The site now ships as a single deployment rooted at
   `https://fish-lsp.dev` (homepage + `/page/*` docs from one `dist/`). If a `docs.` subdomain
   split is ever reintroduced, change `SITE_ORIGIN` in `src/config.ts` accordingly.

6. **`astro-icon` icons** — the original project used `astro-icon` for SVG icons. The current
   layouts render SVG inline instead. The `astro-icon` dependency is still in `package.json` but
   unused; it can be removed or the inline SVGs refactored to use it.
